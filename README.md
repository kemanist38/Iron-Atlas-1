# Iron Atlas 1

Tarayıcı tabanlı strateji oyunu prototipi.

## Şu anda çalışan prototip

- React + TypeScript + Vite
- Lobi ekranı
- Oyun oluşturma / açık oyuna katılma demo akışı
- Komutan listesi
- Etkileşimli stilize dünya operasyon haritası
- Bölge seçme
- Bölge sahipliği ve birlik bilgisi
- Prototip ele geçirme / hareket emri
- Tur artırma

## StackBlitz

Repo StackBlitz ile doğrudan açılabilir. StackBlitz bağımlılıkları tarayıcıdaki çalışma ortamına kurar; yerel bilgisayara kurulum gerekmez.
